# Blog Content Directory

Place blog post markdown files here. Each file should have frontmatter with at minimum:

```yaml
---
title: "Post Title"
date: "2024-03-15"
excerpt: "Short preview text"
---
```

## Naming Convention

Use date-prefixed filenames for easier chronological sorting:
- `2024-06-15-architectural-sonics.md`
- `2024-05-20-refraction-theory.md`
