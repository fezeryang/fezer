这周一到今天，五天时间，我上线了一个完整的求职测评练习平台：[上岸测评](https://shangan-cyan.vercel.app)。这篇文章简单记录一下它是什么、怎么做出来的。

## 它是什么

一句话定位：**求职测评练习平台——言语理解、资料分析、图形推理三科真题练习 + 全真限时模考 + 错题本 + 学情看板 + AI 逐题讲解与举一反三变式题。**

目标用户是准备校招测评笔试的同学，场景是备考期碎片时间刷题、模考、复盘错题。衡量成功的标准只有一个：用户在真实求职测评笔试中通过，也就是「上岸」。

三个产品原则贯穿始终：

- **做题效率优先**——刷题和模考的操作路径做到最短，视觉服务于任务、不干扰任务
- **数据诚实**——所有统计与掌握度都来自真实作答记录，不虚构
- **本地优先**——没有账号系统，学习进度全部存在 localStorage，任何升级不丢数据

## 功能速览

题库是核心资产：**727 道真题**（言语理解 321、资料分析 254、图形推理 152），从 PDF 题库自动解析生成数据模块，515 张图形题配图一并提取为 WebP，与原文严格对齐。

围绕题库是七个功能模块：

- **题库精练**：按科目、考点、难度、作答状态筛选，支持随机抽题
- **全真模考**：限时模拟考场，还原真实笔试节奏
- **错题本**：真实作答记录自动归集
- **AI 变式题库**：AI 生成举一反三变式题
- **考点与速算宝典**：考点分类与速算口诀速查
- **学情看板**：知识图谱、掌握度图表、学习日程热力图
- **图推实验室**：图形推理规律动态实验室，规则分步回放、画布标注

AI 能力做了三层：逐题讲解（讲解 / 图形 / 变式 / 对话四种模式）、全面学情诊断、变式题生成。整个界面是手绘手账风格——暖纸底色、琥珀墨线、标记笔高亮，像一本持续被填写的练习手账，而不是又一个 SaaS 圆角卡片壳。

## 技术要点

几个值得记录的架构决策：

- **AI 信任边界**：React 单页应用 + Express AI 代理。浏览器不持有任何 API key，所有 AI 请求经服务端转发，主引擎失败自动切换兜底模型。部署时把整个 Express 压进 Vercel 的单个 Serverless Function，静态资源走 CDN
- **AI 输出不轻信**：模型返回经宽松 JSON 修复、结构校验、SVG 消毒三道工序。图形推理变式题另有一套纯函数规则引擎独立重算答案做机器校验——AI 出题，机器判卷
- **题库即代码**：PDF 解析产物直接落成 TypeScript 数据模块，每张图有稳定的资源路径，构建时静态打包，不需要运行时数据库
- **零后端状态**：无账号、无服务端存储，全部用户数据在 localStorage，部署和迭代都极轻

## 五天时间线

- **08-31**：立项。一天十一个 commit 把功能核心全部立起来——题库对齐到 727 题并接入知识图谱，双 AI 引擎与兜底链路，图形实验室、变式题与真实数据看板
- **09-02**：完成品牌与本地存储键的统一迁移
- **09-03**：全站手绘重整，五个阶段从纸墨地基做到手账成品，学情看板接入全面 AI 诊断
- **09-04**：Vercel 部署适配（Express 转单 Serverless Function + 静态托管），连踩五个部署坑后上线

全程 31 个 commit、55 个 TS/TSX 文件、约 3.4 万行代码，和 AI 结对完成的比重非常高——从题库解析脚本到视觉重整，大部分代码是先让 agent 出方案再人工收口。
