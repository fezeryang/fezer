# INKBOUND 画线物理跑酷

INKBOUND 是一款以绘画改变道路的 2D 物理跑酷游戏。角色自动向前奔跑，玩家通过鼠标实时画线，在有限的墨水资源下搭桥、铺设坡道，并应对城堡里的断崖、尖刺、水域、箭矢和落石。

## 核心体验

- **真实物理画线**：笔画逐段生成碰撞，能够承载角色，并与游戏中的物体产生物理交互。
- **城堡无尽模式**：在持续生成的城堡道路中规划笔画，收集星星，尝试跑得更远。
- **完整游玩循环**：从主菜单进入游戏，暂停、查看结算并快速重试；设置与本地记录保存在浏览器中。
- **纸页视觉**：笔记本纸、石墨线条与轻柔的蓝色插画共同构成手绘世界。

## 技术与版本

使用 Godot 4.7.2 与类型化 GDScript 开发，通过单线程 Web 导出在浏览器中运行。当前发布内容以电脑端的城堡无尽玩法为主。
