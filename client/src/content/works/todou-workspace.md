# TODŌU 个人 3D 设备工作区

TODŌU 把一套 3D 桌面从展示模型推进成可以探索的个人设备空间。用户可以从同一个场景进入电脑、手机和收音机，直接操作屏幕中的软件，并在设备之间保持连续的工作状态。

## 核心体验

- **设备生态**：Computer、Phone、Radio 共享同一张空间桌面
- **直接探索**：点击设备即可平滑聚焦，首页让 3D 场景成为主角
- **真实交互**：电脑与手机屏幕包含可操作的应用界面和状态反馈
- **跨设备控制**：电脑和手机可以读取并控制收音机的播放、频道与音量
- **暖色工作空间**：浅暖白 WebGL 环境保留复古未来硬件的层次、阴影与材质表现

## 设计方向

硬件保留 Retro / Cyberdeck 个性，屏幕软件则采用更简洁、留白和高层级的信息设计，让复古未来设备与现代产品级 UI 在同一个可进入的空间里形成反差。
