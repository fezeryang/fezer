# 上岸测评

面向求职学生的测评练习平台，把备考做成一本可以持续填写的「上岸手账」。目标只有一个：帮用户在真实求职测评笔试中通过（上岸）。

## 功能模块

- **题库精练**：言语理解 321 题、资料分析 254 题、图形推理 152 题，共 727 道真题，按考点、难度、作答状态筛选
- **全真模考**：限时模拟考场，还原真实笔试节奏
- **错题本**：基于真实作答记录自动归集，复盘不虚构数据
- **AI 变式题库**：AI 生成举一反三变式题，图推变式由规则引擎独立机器校验
- **考点与速算宝典**：考点分类与速算口诀速查
- **学情看板**：知识图谱、掌握度图表、学习日程热力图，支持全面 AI 学情诊断
- **图推实验室**：图形推理规律动态实验室，规则分步回放与画布标注

## 技术特点

- React 19 + Vite + Tailwind CSS v4 单页应用，全站手绘手账视觉风格
- Express 多 provider AI 代理部署为 Vercel 单 Serverless Function，浏览器不持有任何 API key，主引擎失败自动兜底
- AI 逐题讲解（讲解 / 图形 / 变式 / 对话四种模式），输出经宽松 JSON 修复与 SVG 消毒
- 本地优先：无账号系统，所有学习进度存 localStorage
